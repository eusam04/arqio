# 2.5 Módulo de Equipe

## Objetivo

O módulo de equipe será responsável pelo gerenciamento dos participantes de cada projeto.

Ele permitirá organizar os profissionais envolvidos na obra, definir suas funções e controlar quem poderá acessar cada projeto.

---

## Funcionalidades

O módulo deverá permitir:

- Adicionar participantes ao projeto;
- Remover participantes;
- Visualizar a equipe do projeto;
- Definir a função de cada participante;
- Atualizar informações dos participantes;
- Controlar o acesso ao projeto.

---

## Participantes

Cada projeto poderá possuir diferentes profissionais.

Exemplos:

- Arquiteto;
- Engenheiro;
- Mestre de Obras;
- Pedreiro;
- Eletricista;
- Encanador;
- Cliente;
- Colaborador.

Cada participante possuirá uma função dentro do projeto.

---

## Adição de Participantes

Os participantes poderão ser adicionados pelo administrador da empresa ou por usuários autorizados.

Será possível:

- Selecionar um usuário já cadastrado;
- Convidar um novo usuário para participar do projeto.

Após aceitar o convite, o participante passará a fazer parte da equipe.

---

## Organização da Equipe

Cada projeto possuirá sua própria equipe.

### Exemplo

```text
Casa Panora
│
├── Arquiteto
├── Engenheiro
├── Mestre de Obras
├── Pedreiro
├── Cliente
└── Eletricista
```

## Informações do Participante

Cada membro poderá possuir informações como:

Nome;
Foto;
Função;
E-mail;
Telefone.

Outras informações poderão ser adicionadas futuramente.

## Controle de Acesso

A participação em um projeto não garante acesso total às informações.

Cada participante visualizará apenas os recursos permitidos pelas suas permissões.

O gerenciamento detalhado dessas permissões será definido no Módulo 2.7 – Permissões.

## Remoção de Participantes

Usuários autorizados poderão remover participantes da equipe.

A remoção impedirá novos acessos ao projeto, mas manterá o histórico das ações realizadas pelo usuário.

Regras de Negócio
Todo participante deverá estar vinculado a um usuário da plataforma.
Um participante poderá atuar em vários projetos.
Um projeto poderá possuir diversos participantes.
Cada participante deverá possuir uma função.
Apenas usuários autorizados poderão adicionar ou remover participantes.
O histórico das ações do participante deverá ser preservado após sua remoção.
