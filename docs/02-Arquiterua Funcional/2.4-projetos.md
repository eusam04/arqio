# 2.4 Módulo de Projetos

## Objetivo

O módulo de projetos será responsável pelo gerenciamento das obras cadastradas na plataforma.

Cada projeto representará uma obra ou empreendimento e concentrará todas as informações necessárias para sua execução, organização e acompanhamento.

---

## Funcionalidades

O módulo deverá permitir:

- Criar um projeto;
- Visualizar projetos;
- Editar informações do projeto;
- Arquivar projetos;
- Excluir projetos;
- Gerenciar a equipe do projeto;
- Organizar documentos;
- Registrar o histórico da obra;
- Compartilhar informações com os participantes autorizados.

---

## Criação de Projeto

O usuário autorizado poderá criar um novo projeto informando, inicialmente:

- Nome do projeto;
- Cliente;
- Endereço;
- Descrição;
- Responsável técnico;
- Data de início;
- Status.

Outras informações poderão ser adicionadas posteriormente.

---

## Estrutura do Projeto

Cada projeto possuirá seu próprio ambiente.

### Exemplo

```text
Casa Panora
│
├── Informações Gerais
├── Equipe
├── Documentos
├── Fotos
├── Comunicação
├── IA
└── Histórico
```

---

## Informações Gerais

Cada projeto armazenará informações essenciais para identificação da obra.

Exemplos:

- Nome;
- Cliente;
- Endereço;
- Área construída;
- Descrição;
- Responsável técnico;
- Status;
- Data de criação.

---

## Status do Projeto

Cada projeto possuirá um status para facilitar seu acompanhamento.

Exemplos:

- Em planejamento;
- Em andamento;
- Em revisão;
- Concluído;
- Arquivado.

---

## Participantes

Cada projeto possuirá sua própria equipe.

Os participantes poderão exercer diferentes funções dentro do projeto.

Exemplos:

- Arquiteto;
- Engenheiro;
- Mestre de Obras;
- Pedreiro;
- Cliente.

O acesso às informações dependerá das permissões atribuídas a cada participante.

---

## Organização dos Recursos

Todos os recursos do projeto serão centralizados em um único ambiente.

Entre eles:

- Documentos;
- Fotos;
- Comunicação;
- Inteligência Artificial;
- Histórico.

Cada recurso será tratado por seu respectivo módulo da plataforma.

---

## Arquivamento

Projetos finalizados poderão ser arquivados.

O arquivamento permitirá manter o histórico da obra sem que ela apareça entre os projetos ativos.

Os dados permanecerão armazenados e poderão ser consultados posteriormente por usuários autorizados.

---

## Regras de Negócio

- Todo projeto deverá pertencer a uma empresa.
- Um projeto deverá possuir um responsável técnico.
- Apenas usuários autorizados poderão criar projetos.
- Apenas participantes autorizados poderão acessar um projeto.
- Cada projeto possuirá seu próprio conjunto de documentos.
- O histórico do projeto deverá ser preservado mesmo após seu arquivamento.
- Projetos arquivados poderão ser consultados conforme as permissões do usuário.
