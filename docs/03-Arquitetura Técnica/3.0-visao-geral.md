# 3.0 Visão Geral

## Objetivo

Este documento descreve a arquitetura técnica do Arqio.

Seu objetivo é definir como a plataforma será construída, organizando as tecnologias utilizadas, a comunicação entre os sistemas e a estrutura geral da aplicação.

Esta documentação servirá como referência durante todo o desenvolvimento.

---

## Arquitetura

O Arqio será desenvolvido utilizando uma arquitetura cliente-servidor.

A aplicação será dividida em três partes principais:

```text
Frontend
      │
      │ HTTP / HTTPS
      ▼
Backend (API REST)
      │
      ▼
Banco de Dados
```

Cada camada será responsável por uma parte específica da aplicação.

---

## Frontend

O Frontend será responsável pela interface utilizada pelos usuários.

Inicialmente será desenvolvido utilizando:

- React;
- TypeScript;
- Vite.

Suas responsabilidades incluem:

- Exibir informações;
- Enviar requisições para a API;
- Controlar a navegação;
- Gerenciar a experiência do usuário.

---

## Backend

O Backend será responsável por toda a regra de negócio da plataforma.

Será desenvolvido utilizando:

- Node.js;
- Express;
- TypeScript.

Suas responsabilidades incluem:

- Autenticação;
- Autorização;
- Processamento das regras de negócio;
- Comunicação com o banco de dados;
- Disponibilização da API REST.

---

## Banco de Dados

O banco de dados será responsável pelo armazenamento das informações da plataforma.

Será utilizado:

- MongoDB;
- Mongoose.

Serão armazenados dados como:

- Empresas;
- Usuários;
- Projetos;
- Documentos;
- Assinaturas.

---

## Comunicação

O Frontend se comunicará com o Backend utilizando requisições HTTP.

O Backend responderá utilizando o formato JSON.

Exemplo:

```text
Frontend
     │
 GET /projects
     │
     ▼
Backend
     │
 JSON
     ▼
Frontend
```

---

## Segurança

A comunicação entre o Frontend e o Backend utilizará autenticação baseada em JWT.

As senhas serão armazenadas utilizando criptografia com Bcrypt.

---

## Escalabilidade

A arquitetura será desenvolvida para permitir a inclusão de novos módulos sem necessidade de grandes alterações na estrutura existente.
